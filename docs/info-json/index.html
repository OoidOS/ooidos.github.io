Docs

Info.json

Every bundle describes itself in Contents/Info.json (a framework uses Versions/<v>/Resources/Info.json). It’s plain JSON with plain names, and there’s a published JSON Schema for it, ooidos-bundle.schema.json.

A bundle

A universal bundle has one program for each architecture: Contents/OoidOS/x86_64/<executable> and Contents/OoidOS/aarch64/<executable>.

The keys

KeyWhat it means
idA reverse-DNS identifier. Launch services, receipts and preferences all know the bundle by it. It’s the only key you must have.
name, displayNameThe bundle’s name, and the name to show if it’s different.
version, buildThe version people see (“1.2”) and the build number (“42”).
typeapp, framework, plugin, tool or wallpaper.
executableThe name of its program in Contents/OoidOS/.
architecturesx86_64, aarch64, or both for a universal bundle. If none are listed, it’s built for the computer it’s on.
iconIts icon in Contents/Resources/, as PNG or SVG.
categoryAn app’s category, such as public.app-category.utilities.
copyrightThe line shown in About.
licenceAn SPDX expression.
minimumSystemThe oldest version of OoidOS it runs on.
uiElementMarks an app that has no Dock icon and no menu bar of its own.
windowAppIdsThe app ids its windows use, if they’re not its id.
keywordsWords that Search finds it by, as well as its name.
documentTypesThe documents it opens: their names, MIME types or type identifiers, extensions, and its role (editor or viewer).
previewTypesThe types a Peek plug-in shows.

ooid convert Info.plist turns a property list into an Info.json.
