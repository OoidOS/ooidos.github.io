Requirements

Check that your computer meets these requirements before you start.
Processor64-bit Intel or AMD (x86_64).
FirmwareUEFI.
Secure BootTurned off, for now.
DiskAt least 8 GB to install on.
USB stickAt least 2 GB.

Any display the Linux kernel can drive will work. Wi-Fi works with the chips Linux supports, and with Broadcom’s BCM4360 through its own driver.

OoidOS also runs nicely in a virtual machine, such as QEMU with UEFI firmware.
