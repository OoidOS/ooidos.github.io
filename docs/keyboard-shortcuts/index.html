Keyboard shortcuts and gestures

OoidOS’s Command key (⌘) is the key many keyboards mark with a logo or ❖, often called Super. The shortcuts in the first table can be changed or turned off in Settings › Keyboard › Keyboard Shortcuts….

The desktop’s shortcuts

KeysWhat they do
⌘ Tab / ⇧ ⌘ TabMove to the next / previous window
⌘ WClose the window
⌘ MMinimise the window
⌘ QQuit the app
⌘ H / ⌥ ⌘ HHide the app / hide the others
⌥ ⌘ EscForce Quit…
⇧ ⌥ ⌘ EscForce the frontmost app to quit
⇧ ⌘ /Show the Help menu, with its search
⌘ ReturnOpen Terminal
⌘ F2 or Ctrl F2Move to the menu bar, to work its menus with the keyboard
⌘ SpaceSearch
Ctrl ⌘ SpaceEmoji & Symbols
Ctrl Space / Ctrl ⌥ SpaceThe previous / next input source
Ctrl ⌘ QLock the screen
⇧ ⌘ QLog Out…
⌥ ⌘ 8Zoom on or off
⌥ ⌘ = / ⌥ ⌘ -Zoom in / out
Ctrl ⌥ ⌘ 8Invert colours
⌘ F5VoiceOver (the screen reader) on or off

Windows and desktops

KeysWhat they do
Ctrl ⌥ ← → ↑ ↓Tile the window to a half
Ctrl ⌥ F / C / RFill, centre, return to the previous size
Ctrl ⌘ FFull screen
F3 or Ctrl ↑Panorama
Ctrl ↓App Panorama
⌘ F3Show the desktop
Ctrl ← / Ctrl →The desktop to the left / right
Ctrl 1 … Ctrl 9Desktop 1 to 9
F4Launchpad

Search’s panel: ↑ ↓ choose, Return opens, ⌘ Return shows the item in Files, ⌘ C copies its path, Esc closes.

Trackpad gestures

GestureWhat it does
Three fingers upPanorama
Three fingers downApp Panorama
Four fingers left or rightThe next desktop, following your fingers
Thumb and three fingers togetherLaunchpad
Thumb and three fingers apartShow the desktop
Three-finger dragDrag without holding a click (an option in Settings › Trackpad)

Gestures the desktop does not use are passed on to apps, for pinching to zoom and the like.
