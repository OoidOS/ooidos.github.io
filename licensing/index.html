Open source

Licensing

OoidOS is being prepared for an open-source release, and its licence is being chosen now.

We’ll name the licence here as soon as it’s chosen.

Until then, the source code and the live USB image aren’t public. The image is coming soon, and the home page will link to it. Contributions will open together with the licence: see Contributing.

What OoidOS is made of

OoidOS is built on lots of free software: the Linux kernel, the GNU toolchain, wlroots, PipeWire, CUPS, Samba, OpenSSH and many more. Each one keeps its own licence. Every source is pinned, so it’s always clear which version of which project is inside.

Some of OoidOS’s own parts already have their licences:

PartLicence
OoidOS’s alert, startup and interface soundsCC0 1.0, public domain
Emoji (Noto Color Emoji)SIL Open Font License 1.1
Icons drawn from Lucide’s shapesISC
The PDF viewer, built on PopplerGPL, as Poppler is

One Wi-Fi driver that some laptops need, Broadcom’s wl, isn’t free software. It’s going to become an optional package, offered only to computers that need it, so OoidOS itself stays free software.
